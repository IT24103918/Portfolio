Since your GitHub username is `IT24103918`:

1. Open PowerShell or Terminal in this folder:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of developer portfolio"
   git branch -M main
   ```

3. Link and push your code:
   ```bash
   git remote add origin https://github.com/IT24103918/portfolio.git
   git push -u origin main
   ```

4. Go to **Repository Settings** > **Pages** > Select branch `main` and root folder `/` > Click **Save**.
5. Your portfolio will be live at:
   `https://IT24103918.github.io/portfolio/`
